Arquitetura

Sistema modular com pipeline automatizado de descoberta, extracao, pontuacao e publicacao de skills.

Modulos

clp.scout

Descobre repositorios GitHub por palavras-chave

clp.extractor

Analisa README e gera SKILL.md

clp.scorer

Avalia qualidade com 10 criterios

clp.publisher

Publica skills aprovadas

clp.tracker

Monitora atualizacoes de repositorios

clp.dashboard

Dashboard web estilo CLI/IDE

Instalacao

bash
$ pip install continuous-learning-pipeline

Comandos

bash
$ clp scout --keywords "agents,ai" --max-results 10
$ clp extract --repo langchain-ai/langchain
$ clp score --skill ./SKILL.md
$ clp publish --skill ./SKILL.md
$ clp dashboard --html --serve
$ clp pipeline --keywords "agents,ai" --max-results 5
