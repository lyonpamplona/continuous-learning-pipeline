Continuous Learning Pipeline

Descoberta automatizada de skills para agentes de IA

Python 3.10+ MIT License Alpha

Visão Geral

O CLP é um sistema automatizado que descobre, extrai, pontua e publica Agent Skills a partir de repositórios GitHub. Funciona como ferramenta standalone ou se integra com frameworks de agentes como Hermes Agent.

Instalação

Standalone

$ pip install continuous-learning-pipeline

Com Hermes Agent

$ pip install continuous-learning-pipeline[hermes]

Do repositório

$ git clone https://github.com/lyonchristopher/continuous-learning-pipeline.git
$ cd continuous-learning-pipeline
$ pip install -e .

Comandos Rápidos

$ clp scout --keywords "agents,ai" --max-results 10
$ clp extract --repo langchain-ai/langchain
$ clp score --skill ./SKILL.md
$ clp publish --skill ./SKILL.md
$ clp dashboard --html --serve
$ clp pipeline --keywords "agents,ai" --max-results 5

Dependências

  • pyyaml >= 6.0
  • requests >= 2.31.0
