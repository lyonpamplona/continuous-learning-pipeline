clp.scout

Descobre repositorios relevantes no GitHub usando a API de busca.

MetodoParametrosRetornaDescricao
search_trending(keywords, max_results) keywords: list, max_results: int list[dict] Busca repositorios por palavras-chave ordenados por estrelas
get_repo_details(full_name) full_name: str dict Obtem detalhes completos de um repositorio
save_results(results, output_path) results: list, output_path: str str Salva resultados em arquivo JSON
python
from clp.scout import Scout
from clp.config import Config

config = Config()
scout = Scout(config)
results = scout.search_trending(["agents", "ai"], max_results=10)
for repo in results:
  print(f"{repo['full_name']} - {repo['stars']} stars")

clp.extractor

Analisa repositorios e gera arquivos SKILL.md.

MetodoParametrosRetornaDescricao
fetch_readme(full_name) full_name: str str Busca conteudo do README de um repositorio
analyze_readme(readme) readme: str dict Analisa README para extrair proposito, secoes, comandos
identify_workflows(readme_info, metadata) readme_info: dict, metadata: dict list[dict] Identifica workflows reutilizaveis
generate_skill_md(...) repo_name, metadata, readme_info, workflows str Gera conteudo SKILL.md completo
extract(full_name, skill_name) full_name: str, skill_name: str str Pipeline completo: busca metadata, README, gera SKILL.md

clp.scorer

Avalia qualidade de SKILL.md com 10 criterios objetivos.

MetodoParametrosRetornaDescricao
load_skill(path) path: str dict Carrega e parseia SKILL.md (frontmatter + corpo)
score(skill_data) skill_data: dict dict Retorna score (0-100), decisao (PASS/REJECT), checks

Criterios de Avaliacao

CriterioPontosDescricao
Frontmatter completo15name, trigger, description, version presentes
Description ≤ 60 chars10Descricao curta e objetiva
Termina com ponto5Descricao termina com "."
Secoes essenciais20"When to Use" e "Procedure" presentes
Procedure ≥ 3 passos15Procedimento com pelo menos 3 passos
Pitfalls ≥ 2 itens10Pitfalls com pelo menos 2 itens
Sem palavras de marketing5Sem termos como "revolutionary"
Tamanho ≤ max_size5Arquivo dentro do limite de tamanho
Author credita humano5Autor nao e "CLP Pipeline"
Name valido5Nome segue padrao [a-z][a-z0-9-]*

clp.lib

Interface de biblioteca para uso em outras CLIs com agentes.

python
from clp.lib import CLP

# Criar instancia
pipeline = CLP(config={"github_token": "seu_token"})

# Descobrir repositorios
repos = pipeline.scout(keywords=["agents", "ai"])

# Extrair skill
skill = pipeline.extract("langchain-ai/langchain")

# Pontuar
result = pipeline.score(skill)

# Publicar
pipeline.publish(skill, name="langchain")

# Pipeline completo
result = pipeline.pipeline(keywords=["agents"], max_results=5)
