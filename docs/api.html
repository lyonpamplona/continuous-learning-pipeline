clp.scout

Classe Scout

Descobre repositórios relevantes no GitHub usando a API de busca.

MétodoParâmetrosRetornaDescrição
search_trending(keywords, max_results) keywords: list, max_results: int list[dict] Busca repositórios por palavras-chave ordenados por estrelas
get_repo_details(full_name) full_name: str dict Obtém detalhes completos de um repositório
save_results(results, output_path) results: list, output_path: str str Salva resultados em arquivo JSON

Exemplo de Uso

from clp.scout import Scout
from clp.config import Config

config = Config()
scout = Scout(config)
results = scout.search_trending(["agents", "ai"], max_results=10)
for repo in results:
    print(f"{repo['full_name']} - {repo['stars']} stars")

clp.scorer

Classe Scorer

Avalia qualidade de SKILL.md com 10 critérios objetivos.

MétodoParâmetrosRetornaDescrição
load_skill(path) path: str dict Carrega e parseia SKILL.md (frontmatter + corpo)
score(skill_data) skill_data: dict dict Retorna score (0-100), decisão (PASS/REJECT), checks

Critérios de Avaliação

CritérioPontosDescrição
Frontmatter completo15name, trigger, description, version presentes
Description ≤ 60 chars10Descrição curta e objetiva
Termina com ponto5Descrição termina com "."
Seções essenciais20"When to Use" e "Procedure" presentes
Procedure ≥ 3 passos15Procedimento com pelo menos 3 passos
Pitfalls ≥ 2 itens10Pitfalls com pelo menos 2 itens
Sem palavras de marketing5Sem termos como "revolutionary"
Tamanho ≤ max_size5Arquivo dentro do limite de tamanho
Author credita humano5Autor não é "CLP Pipeline"
Name válido5Nome segue padrão [a-z][a-z0-9-]*
